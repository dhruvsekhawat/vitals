# Code of conduct

This is a small project maintained in spare time. The rules are short.

Be direct and be kind. Disagree with code, not with people. Assume the other person is trying to help, because they almost always are.

Bug reports with numbers beat opinions. "Vitals said 12%, ps said 48%" is useful. "It is wrong" is not.

No harassment, no personal attacks, no bringing someone's identity into a technical discussion. Anyone doing that gets one warning, then loses the ability to participate.

If something happens that you do not want to raise in public, use the private security reporting link in SECURITY.md. It reaches the maintainer and nobody else.
